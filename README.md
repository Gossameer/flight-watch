# Flight Watch 

Небольшой Python-скрипт, который проверяет цены на авиабилеты из Москвы в Бангкок.

Если находит подходящий билет, отправляет сообщение в Telegram.

## Что умеет

- проверять цены на билеты MOW → BKK
- проверять несколько дат
- искать только прямые рейсы
- искать билеты до заданной цены
- отправлять найденный вариант в Telegram

## Сейчас настроено

- Москва → Бангкок
- 1–7 ноября 2026
- только прямые рейсы
- цена до 25 000 ₽
- билет в одну сторону
